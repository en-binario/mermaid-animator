# Spec Delta

## Purpose

Guides new users from installation to their first animated, annotated and exported diagram in a few minutes.

## ADDED Requirements

### Requirement: Getting-started walkthrough
The extension SHALL contribute the walkthrough *Get started with Mermaid Animator* with steps to open a sample diagram, step through it, switch views, add an annotation and export, each with a description and an action button, available in English and Spanish.

#### Scenario: Open the sample
- **WHEN** the user runs the walkthrough's first step action
- **THEN** a sample Mermaid diagram opens in an untitled editor with its animator panel beside it
