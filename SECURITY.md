# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately using **Report a vulnerability** under this repository's **Security** tab (GitHub Private Vulnerability Reporting), or email `admin@enbinario.com`.

Please do not open a public GitHub issue for a security vulnerability before a fix is released.

## Scope

Mermaid Animator runs locally inside VS Code with a strict Content Security Policy in its webview and makes no network requests. Diagrams and exported files stay on your machine.
