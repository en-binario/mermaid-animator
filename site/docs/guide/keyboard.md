# Keyboard shortcuts

Press `?` in the panel to see every shortcut.

## In the panel

| Key | Action |
|---|---|
| `Space` / `K` | Play / pause |
| `→` / `←` | Next / previous step |
| `Shift+→` / `Shift+←` | Next / previous chapter |
| `Home` / `End` | First / last step |
| `G` | Go to step (number or text) |
| `[` / `]` | Slower / faster |
| `L` | Loop |
| `I` / `O` | A–B loop start / end (`Shift+I` clears) |
| `+` / `-` | Zoom in / out (also in the toolbar) |
| `0` | Fit diagram |
| `F` | Frame current step |
| `C` | Camera follow on / off |
| `T` | Sequence / topology view |
| `S` | Split view |
| `D` | Inspector |
| `/` | Search |
| `R` | Transcript view |
| `P` | Presentation mode |
| `E` | Export |
| Click a header | Focus a participant (`Ctrl`/`Cmd` adds) |
| `B` / `.` | Blank screen (presenting) |
| `Z` (hold) | Laser pointer (presenting) |
| `Esc` | Close, clear focus, end presentation |
| `?` | All shortcuts |

## From the editor

While an animator panel is active:

| Command | Windows and Linux | macOS |
|---|---|---|
| Play / Pause | `Ctrl+Alt+Space` | `Cmd+Alt+Space` |
| Next Step | `Ctrl+Alt+→` | `Cmd+Alt+→` |
| Previous Step | `Ctrl+Alt+←` | `Cmd+Alt+←` |

**Open Animated Preview to the Side** is `Ctrl+K Alt+M` (`Cmd+K Alt+M` on macOS) in an editor with a diagram. Every
command and its identifier is in the [commands reference](../reference/commands.md).
